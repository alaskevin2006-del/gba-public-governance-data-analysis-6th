> 以真实运行结果替换；任何未经运行的实验条件都不会出现在结论中。

## 4.1 研究目标与反事实仿真定位

第三章的实证分析揭示了涉灾 AIGC 谣言的生成套路、传播特征与官方治理的基本形态，但其数据基础是**事后留痕**（官方通报、平台处置、公开评论），存在两个无法由观测数据弥补的缺口：

1. 观测不到"如果政府晚介入几小时会怎样"——真实事件只有一条已实现的时间路径；
2. 观测不到"如果换成另一种回应形态会怎样"——真实事件只采用过一种回应文本。

本章的目标是**用受控的多智能体仿真补上这两类反事实对照**，回答三个问题：

- **问题一（形式）**：在相同初始条件下，以高拟真视觉描述为特征的 AIGC 谣言，是否比传统文字谣言引发更强的传播反应？
- **问题二（时点）**：在同一版辟谣内容下，第 1、4、12 模拟小时介入的传播后果有何差异？
- **问题三（形态）**：在相同介入时点下，传统公文式辟谣与"数智实证型"辟谣的传播后果有何差异？

**本章研究的定位必须前置说明**：这是一项**基于真实事件材料构建场景的探索性反事实仿真**。仿真中的 Agent 不是真实人群抽样，每个体的行为由大语言模型（LLM）生成；仿真的"小时"是模型时间单位，**不等于经过现实校准的现实小时**；现有微博数据仅够用于场景构建与有限的形式合理性检查，不足以校准传播速率参数。因此本章的全部比较都是**在同一套模型假设下的条件性比较**，不能被解释为现实政策效果的因果估计。

## 4.2 MiroFish 技术架构与使用方式

本研究采用 MiroFish（上游 Commit `7657031`）作为仿真平台，其底座为 CAMEL-AI 的 OASIS 双平台社交模拟器，并接入 Zep Cloud 作为实体记忆与图谱存储。

| 组件 | 版本 / 取值 |
|---|---|
| MiroFish 上游 | Commit `7657031` |
| 模拟器 | `camel-oasis 0.2.5` / `camel-ai 0.2.78` |
| 图谱与记忆 | Zep Cloud（`zep-cloud 3.25.0`） |
| 决策模型 | `deepseek-chat`（OpenAI 兼容接口） |
| 运行环境 | Python 3.12（uv 管理的虚拟环境），Flask 后端 :5001 |
| 时间尺度 | `minutes_per_round = 60`（实测自 `simulation_config.json`，非假设值） |

**运行链路**：种子材料 → 本体抽取（LLM） → Zep 知识图谱 → Agent 画像与配置生成 → 双平台（Twitter / Reddit）环境初始化 → 逐轮推进（每轮抽取若干被激活的 Agent，由 LLM 决定其动作） → 动作日志（`actions.jsonl`）与平台数据库落盘。

### 4.2.1 对上游的两处受控修改

上游版本存在两处使本研究无法按设计执行的问题，本工程以补丁形式做了最小必要修改（补丁脚本 `mirofish/scripts/apply_runner_patch.py`，补丁前后文件均已入库以便审计）：

1. **补齐定时事件字段**：上游 `simulation_config_generator.py` 将 `event_config.scheduled_events` 恒置为 `[]`，且运行器中不存在任何消费该字段的代码（已全仓检索确认）。若不处理，"第 k 小时介入"这一核心实验条件**无法实现**。补丁在指定轮次进入 Agent 自主动作之前，向指定 Agent 注入一条发帖动作；注入的轮次、内容、发布者均写入配置并在运行日志中留痕。
2. **随机数种子生效**：补丁使配置项 `random_seed` 传递给 `random.seed()`，令 Agent 激活抽样在 Python 侧可复现。

两者都**不修改 Agent 的自主决策逻辑**，只改变研究者可控的部分。

### 4.2.2 关于运行平台的说明

OASIS 的 Twitter 通道在推荐排序环节依赖 HuggingFace 上的在线模型 `Twitter/twhin-bert-base`。在本次实验环境中，对该域名的直连不稳定，会在若干轮后出现连接失败、重试耗尽直至进程崩溃；同时，预实验实测发现 Twitter 侧**只产生发帖行为**，评论、点赞、点踩等本研究关心的互动几乎全部发生在 Reddit 侧，且 `REPOST`（转发）在两组中均无人使用。

因此本研究**统一以 Reddit 讨论类平台作为仿真场景**。这一选择使每组运行的时间与调用开销约减半，从而在预算内获得更多次独立重复。代价是：结论不做跨平台外推，Twitter 侧的转发级联行为不在本章观测范围内。

### 4.3.2 Agent 画像的生成与 Agent 数量

Agent 由 Zep 图谱实体转换而来：**Agent 数量 = 图谱实体数 × 0.9**（由上游 `_generate_time_config` 计算，不可由研究者直接指定）。本次制备得到 **8 个 Agent**，涵盖：

| 类型 | 实例（由 LLM 依真实材料生成） |
|---|---|
| Person（个人） | 温州本地自媒体运营者陈航、AI 造假者高某某 |
| RumorForwarder | 中小资讯类自媒体工作室 |
| GovernmentAgency / Organization | 上海公安机关、浦东警方、宁波/温州公安机关 |
| 官方辟谣平台 | 中国互联网联合辟谣平台 |

每个 Agent 都带有由 LLM 依据真实材料生成的人物设定（身份背景、发言风格、立场、事件记忆），这是当前 LLM 驱动的 Agent 仿真研究的通行做法，也是本研究"现实合理性"的主要来源。

**必须承认的局限**：8 个 Agent 且机构类占比偏高（5/8）。因此本实验只能观察"小群体讨论内的相对差异"，传播规模量级不具外部效度；公众视角的行为由少量个人 Agent 承担，这是本章数据薄弱之处。曾尝试通过扩充种子提升实体抽取数量，但受限于实体抽取稳定性与时间成本，本次未增大规模，作为改进方向写入 4.11。

## 4.4 网络、行为规则与时间参数

| 参数 | 取值 | 说明与理由 |
|---|---|---|
| `minutes_per_round` | 60 | 实测自配置文件；故第 k 轮 ≈ 模拟第 k 小时 |
| 总观察轮数 | 16 | 保证第 12 小时介入后仍有 4 轮观察窗口 |
| `activity_level` | 0.9 | 覆写值（原生成值偏低且仅工作时段活跃） |
| `active_hours` | 全 24 小时 | 覆写值。原值使仿真自 hour 0 起零自主动作（见 4.5） |
| 每轮激活 Agent 数 | 6–8（视该轮活跃度） | 覆写为固定区间，避免早晚 $\times$ 0.05 的峰谷衰减 |
| `agents_per_hour_min/max` | 6 / 8 | 同上 |
| `random_seed` | 每次运行不同（如 20261022、20261023…） | 仅保证 Python 侧抽样可复现；LLM 采样本身不可复现 |
| 社交网络结构 | 由 OASIS 依据平台默认规则生成（初始无预置关注关系） | 关注/屏蔽关系在仿真中由 Agent 自主形成（FOLLOW/MUTE） |

**上述活跃度覆写参数是建模假设，不是现实标定结果。** 其作用是让传播过程在有限轮次内可被观测；由于所有实验条件使用完全相同的活跃度参数，组间差异仍可归因于目标变量。

## 4.5 模型假设与技术有效性检查

正式实验前做了五项必验收，逐条实测：

1. **Agent 是否真实活跃**：初始运行中，LLM 生成的 `active_hours` 被限定在工作时段（如 [9,10,11,14,15,16]），而仿真自 hour 0 起始，激活判定 `if current_hour not in active_hours: continue` 使所有自主动作被跳过——表现为整轮循环 0.1 秒完成、动作全部来自预置初帖。修复后，Agent 在每一轮都可能被调用。
2. **是否形成真实传播互动**：修复后评论（`CREATE_COMMENT`）、点赞（`LIKE_POST` / `LIKE_COMMENT`）、点踩（`DISLIKE_POST`）均已稳定出现，多个 Agent 参与；**转发 `REPOST` 始终为 0**，因此本章不把发帖量称为"传播规模"。
3. **初始状态是否可控**：`event_config.initial_posts` 被研究者严格替换为目标谣言文本，剔除 LLM 自行生成的初始帖（含可能提前泄露官方辟谣的帖子），每次运行记录被剔除的条数。需注意：图谱自带的公安、辟谣平台类 Agent 仍可能**自主**发布辟谣性质内容，这属于被允许的自主行为，因此在结果解读中，"无官方干预"是指**研究者未注入任何官方辟谣事件**，而非"环境中不存在官方声音"。
4. **干预是否真正生效**：每次运行结束后，以干预文本的唯一标记串检索 `actions.jsonl`，核验其首次出现的轮次是否与设定一致。正式实验结果中的 `intervention_verify` 字段逐条记录了该项核验。
5. **指标能否正确解析**：改用 `actions.jsonl` 中的 `round_start` / `round_end` 标记还原完整轮次序列（原先用 `timeline` 接口会漏掉无动作的轮次，导致"实际 16 轮只解析出少数几轮"的错误）。

## 4.6 三组实验设计与控制变量

三组实验**共用同一批 Agent、同一张初始网络、同一份种子材料、同一套时间参数与活跃度配置**，并复用同一个已完成画像制备的仿真实例；每完成一组，先停止并关闭环境、删除上一组的数据库与动作日志，再开始下一组，以防止组间状态污染。

### 实验一：谣言形式

| 条件 | 刺激内容 | 干预 |
|---|---|---|
| E1A | 传统文字谣言 4 条 | 无（同时作为实验二、三的共同基线） |
| E1B | AIGC 高拟真图文谣言 4 条 | 无 |

**重要限定**：MiroFish 当前版本不支持向 Agent 呈现真实图片或视频帧。因此 E1B 是**以"高拟真视觉描述"为刺激的文本代理实验（text-proxy）**，而非真实多模态刺激实验。它可以检验"当谣言文本携带更强的现场感与画面描述时传播是否更强"，但**不能**等价于真实 AIGC 图片的视觉说服力。

### 实验二：辟谣介入时点

| 条件 | 干预内容 | 注入轮次（≈模拟小时） |
|---|---|---|
| E2R1 | 传统公文式辟谣 | 第 1 轮 |
| E2R4 | 传统公文式辟谣 | 第 4 轮 |
| E2R12 | 传统公文式辟谣 | 第 12 轮 |

三者使用**完全相同的**辟谣文本（改写自真实通报 P1-01，未添加新事实），唯一差别是注入时刻；基线统一复用 E1A。

### 实验三：辟谣回应形态

| 条件 | 干预内容 | 注入轮次 |
|---|---|---|
| E2R4（≡ E3A） | 传统公文式辟谣：定性结论 + 处罚结果 + 警方提示 | 第 4 轮 |
| E3B | 数智实证型辟谣：定性结论 + 客观灾情数据 + AI 造假识别要点 + 民生保供信息 + 核验渠道 | 第 4 轮 |

**重要限定**：两组在文本长度、证据条目数、表达方式与呈现结构上**同时存在差异**，因此只能陈述"两种综合回应策略之间的条件性差异"，不能声称识别了单一因素（例如"是否附数据"）的因果效应。

## 4.7 评价指标及其计算方法

所有指标由 `mirofish/scripts/analyze_formal_v2.py` 从原始 `actions.jsonl` 直接计算，脚本、逐条分类结果与原始日志一并归档，任一指标都可回溯到具体动作记录。

### 4.7.1 轮次与时间标签

由日志中 `round_start` 事件的 `simulated_hour` 字段直接读取（而非推导），得到映射：round 0 与 round 1 的 `simulated_hour` 均为 0，round k（k≥2）对应 `simulated_hour = k−1`。据此统一口径：

| 概念 | 定义 |
|---|---|
| **round 0 = 初始态** | 研究者注入的 4 条初始谣言帖。**不是模拟轮**，不计入任何自发互动指标 |
| **第 k 模拟小时** | 对应 round = k，覆盖模拟时间 `[(k−1)×60, k×60)` 分钟 |
| 去重规则 | round ≥ 1 中与 round 0 同作者同内容的重复记录（初始帖被记录了两次）予以剔除 |

因此"第 1 / 4 / 12 模拟小时介入"等价于"第 1 / 4 / 12 轮介入"。**需反复强调：模拟小时是模型内部时间单位，不等于经校准的现实小时。**

### 4.7.2 指标口径

| 指标 | 口径 |
|---|---|
| 自发互动量 | round 1–16 内：`CREATE_POST + CREATE_COMMENT + REPOST + LIKE/DISLIKE(POST/COMMENT)`；不含 round 0 初始帖，不含 `DO_NOTHING / REFRESH / SEARCH_* / TREND / MUTE / FOLLOW` |
| **谣言相关互动量** | 被判定为"谣言放大类"的内容条数 **+** 指向谣言类内容的互动条数 |
| 辟谣相关互动量 | 被判定为"辟谣/求证类"的内容条数 **+** 指向辟谣类内容的互动条数 |
| 互动指向性 | 利用 `LIKE_POST / DISLIKE_POST / LIKE_COMMENT` 动作中记录的被互动对象文本（`post_content` / `comment_content`）判定其指向哪一方言论 |
| 传播峰值与达峰轮次 | 谣言相关互动量序列的最大值及其所在轮次 |
| 固定观察窗 | 为支持不同介入时点之间的可比比较，统一取"介入轮 k 起连续 5 轮"（k 至 k+4）作为干预后固定窗口 |

### 4.7.3 内容立场判定

采用 `content_classifier_v2.py`（**已重构**，详见 `deliverables/实验数据质量复核报告.md` 第 3 节）。核心设计：

- 辟谣侧分**强标记**（否定真实性、说明查处）、**中弱标记**（劝阻转发、指向官方渠道）、**反悔语式标记**（说话人承认曾传播并劝阻他人）三组，任一命中即判入辟谣侧；
- 谣言侧保留**断言虚假灾情为真**与**扩散动员**两类标记；
- 增设**引号剔除**：检测谣言断言前先剔除引号内片段，以正确处理"别光转'坠楼'那种吓人话了"这类**引用式否定**；
- 逐条输出文本、判定与命中证据，存于各运行 `content_labels_audit.csv`，可逐条核验。

**已知歧义**：质疑官方但不断言灾情的表达（如"官方说没有就没有？怎么光盯着我们普通老百姓"）判为中性，不计入任何一侧。

### 4.7.4 明确不予量化的指标

恐慌强度、囤货倾向、政府信任度、二级传播深度与级联树。前三者在本仿真中不存在可核验的操作化字段；传播树不可重建（`CREATE_COMMENT` 的 `action_args` 不含被评论对象，且 `REPOST` 计数为 0）。这些只作为定性观察或研究局限列出，**不以数值形式出现在本章**。

### 4.8.1 运行基本情况与数据核查

六个条件均已完成至少一次**通过完成度审计**的真实运行。"通过"的判据是——16 个模拟轮次全部有动作记录**，且**子进程输出中不出现 HTTP 402 余额不足错误。下表同时列出被判定作废的运行及其原因，以保证数据筛选过程可审计。

**有效运行（纳入本章全部分析）**

| 条件 | 重复次数 | 运行规模 | 随机种子 | 干预核验 |
|---|---|---|---|---|
| E1A 传统文字谣言（共同基线） | **3** | 8 Agent × 16 轮 | 20261022 / 20261023 / 20261024 | 无干预 |
| E1B AIGC 高拟真图文（文本代理） | 1 | 8 Agent × 16 轮 | 20261022 | 无干预 |
| E2R1 第 1 模拟小时介入 | 1 | 8 Agent × 16 轮 | 20261022 | 第 1 轮命中 ✔ |
| E2R4 第 4 模拟小时介入（≡ E3A） | 1 | 8 Agent × 16 轮 | 20261022 | 第 4 轮命中 ✔ |
| E2R12 第 12 模拟小时介入 | 1 | 8 Agent × 16 轮 | 20261022 | 第 12 轮命中 ✔ |
| E3B 第 4 小时·数智实证式辟谣 | 1 | 8 Agent × 16 轮 | 20261022 | 第 4 轮命中 ✔ |

其中 E1A 是唯一的三次重复组，**全章的组间差异判读都以它的组内变异作为噪声尺度**（见 4.9）。

**已作废运行（共 8 次，不参与任何比较，保留日志备查）**

| 运行 | 作废原因 |
|---|---|
| E2R4_rep0 | `process_stdout.txt` 含 30 次 HTTP 402，round 12–16 无任何动作记录 |
| E3B_rep0 | 执行环境的文件批量删除阈值保护拦截导致子进程 31 秒退出，未产出轮次 |
| E1B / E2R1 / E2R4 / E2R12 的 rep2 | 账户余额耗尽，分别出现 99 / 102 / 20 / 96 次 402，轮次严重缺失 |
| E3B_rep2 | 账户余额耗尽，出现 96 次 402，仅 4 个轮次有动作记录 |

**必须指出的历史更正**：本项目曾在未做完成度审计的阶段，依据 E2R4_rep0 得出"第 4 小时介入后谣言相关互动连续 12 轮为 0，长尾抑制最彻底"的表述。经核查，该现象是**账户余额耗尽导致模型调用失败**的假象，不是治理效果。本章已撤回该表述，改由通过审计的 E2R4_rep1 数据替代。

**经费约束的如实说明**：补齐重复是本轮的主要目标，但 DeepSeek 采用延迟入账，实时余额读数严重滞后于真实消耗——本轮补跑启动时读数显示 ¥9.86，实际仅完成 1 次完整运行（E1A_rep3）后余额即被此前遗留账单击穿至负值，后续三组均在轮次中途 402 中断。据此修正成本认知：**单次完整运行的真实成本约为 ¥4–5**，此前"某次运行仅耗 ¥0.3"是延迟入账造成的读数假象。因此除 E1A 外的五个条件仍停留在 1 次重复，这是外部资源约束，不是方法选择。

### 4.8.3 三组谣言相关互动的逐轮形态

谣言相关活动的共同形态是**在第 1 轮冲高后迅速衰减**。三次重复的基线给出了强一致的证据——
E1A 的三次运行均在第 1 轮达到峰值（11 / 8 / 12 条），此后逐轮衰减：

| 轮次区间 | E1A | E1B | E2R1 | E2R4 | E2R12 | E3B |
|---|---|---|---|---|---|---|
| 1–2 | 16.7 | 14 | 13 | 11 | 15 | 20 |
| 3–4 | 2.7 | 2 | 1 | 4 | 2 | 2 |
| 5–8 | 1.0 | 6 | 2 | 0 | 0 | 3 |
| 9–16 | 1.0 | 1 | 0 | 1 | 0 | 0 |

四个可被读出的事实：

1. **峰值集中在第 1 轮且形态可复现**——E1A 三次独立运行的达峰轮次完全一致，这是本章唯一经过重复验证的动态特征。
2. **此后各条件均迅速衰减至零星水平**（区间合计多为 0–2）。
3. **无干预的基线组 E1A 同样呈现这一形态**——它并未因缺少官方辟谣而维持住谣言讨论。
4. **第 12 小时介入组 E2R12 的谣言相关活动在第 5 轮即归零，比干预落地早了 7 个模拟小时**；
   也就是说，在该条件下不存在"干预压制了正在进行的传播"，因为传播早已自行结束。

对应图件：**图 4-1**（介入时点对比）、**图 4-2**（回应形态对比）、**图 4-4**（谣言形式对比）、**图 4-5**（各条件核心指标）。

### 4.8.4 实验一：谣言形式

AIGC 图文组（E1B）的谣言相关互动为 23，传统文字组（E1A）为 21.3 ± 1.15，相对基线 +1.7，约 **1.4 倍组内标准差**；谣言相关占比 17.4% 对 14.4%，约 **2.4 倍**。方向虽与假设一致（AIGC 更强），但幅度小，且 E1B 仅有单次观测。

**结论**：本仿真**未**提供"AIGC 高拟真形式传播更强"的可靠证据，只能记为方向上的弱提示。（须注意 E1B 是文本代理刺激，见 4.6 的限定。）

### 4.8.5 实验二：辟谣介入时点

三个介入条件的谣言相关互动为 16 / 16 / 17，基线为 21.3。三个介入组**全部低于基线**，但三者之间**互不相同也不呈单调**——第 1 小时与第 4 小时同为 16，第 12 小时为 17。

**结论（需分两层陈述）**：

1. **"有无辟谣介入"这一层，数据给出了超出噪声的分离**：三组相对基线的差为 −5.3 / −5.3 / −4.3，约 3.7–4.6 倍组内标准差；在排除总活跃度差异的占比口径下仍相差 1.1–2.6 倍（详见 4.9）。这是本研究中**唯一方向一致、且在两种口径下都与基线分离**的一组差异。
2. **"介入时点早晚"这一层，数据不支持单调关系**：三个时点结果几乎重合，不支持"越早越好"，也不支持"存在某一最优时点"。

第 2 点的直接原因见 4.8.3：谣言相关活动在多数条件下于干预落地之前即已接近消失，留给不同时点产生差异的空间极小。

### 4.8.6 实验三：辟谣回应形态

第 4 小时介入的两个条件下，数智实证式（E3B）为 25，反**高于**公文式（E2R4）的 16，也高于无干预基线的 21.3（相对基线 +3.7，约 3.2 倍组内标准差；占比口径 +2.3 倍）。

**结论**：本仿真**没有**提供"数智实证式辟谣优于公文式"的证据，观测到的方向与假设相反。须强调两组回应文本在长度、条目数、结构与措辞上同时存在差异，因此即便出现差异也只能陈述"两种综合回应策略之间的条件性差异"，不能归因于单一要素，更不能据此否定数智实证式回应。

## 4.9 组间比较与可支持的推断强度

### 4.9.1 方差基准：以 E1A 的三次重复作为噪声尺度

判断组间差异能否归因于实验变量，唯一可靠的参照是**在完全相同条件下重复运行所产生的波动**。基线组 E1A 完成了 3 次重复，提供了本章的噪声尺度：

| 指标 | E1A 三次观测 | 均值 | 样本标准差 | 极差 |
|---|---|---|---|---|
| 自发互动总量 | 151 / 153 / 140 | 148.0 | 7.00 | 13 |
| **谣言相关互动** | 20 / 22 / 22 | **21.3** | **1.15** | 2 |
| 辟谣相关互动 | 127 / 124 / 115 | 122.0 | 6.24 | 12 |
| 谣言相关占比 | 13.25% / 14.38% / 15.71% | 14.4% | 1.23 pp | 2.46 pp |

### 4.9.2 排除混淆：总活跃度差异不足以解释结论

各条件的自发互动总量并不相等（130–153），因此"谣言相关互动低"有可能只是"该组整体不活跃"。为此在**占比口径**下重算一遍——即用"谣言相关互动 / 自发互动总量"消除整体活跃度的影响：

| 条件 | 谣言相关互动 | 相对 E1A | 谣言相关占比 | 相对 E1A | 两种口径方向 |
|---|---|---|---|---|---|
| E1A 基线 | 21.3 ± 1.15 | — | 14.4% ± 1.23 | — | — |
| E1B AIGC | 23 | +1.4σ | 17.4% | +2.4σ | 一致（高于基线） |
| E2R1 第 1 小时 | 16 | **−4.6σ** | 11.4% | **−2.5σ** | 一致（低于基线） |
| E2R4 第 4 小时 | 16 | **−4.6σ** | 11.2% | **−2.6σ** | 一致（低于基线） |
| E2R12 第 12 小时 | 17 | **−3.7σ** | 13.1% | −1.1σ | 一致（低于基线） |
| E3B 数智实证 | 25 | **+3.2σ** | 17.2% | +2.3σ | 一致（高于基线） |

两种口径的方向完全一致，**说明观测到的差异不是由总体活跃度差异驱动的**。佐证是：辟谣相关互动在 E2R1（124）与 E2R4（126）几乎与基线（122）持平，而谣言侧低了约 5 条——这是**结构性变化**而非整体降温。

### 4.9.3 σ 倍数不是 p 值：必须附带的三条限定

上表的 σ 倍数**只能读作"差异相对于已观测波动的倍数"，不是显著性检验结果**：

1. E1A 的标准差基于 **n = 3**。三个样本估出的标准差本身极不稳定，其真实值有相当大的可能落在估计值的 0.5–2 倍之间。若真实组内标准差比估计值大一倍，上表所有 σ 倍数都要折半。
2. 除 E1A 外的五个条件**均只有 1 次观测**，其单次抽样误差未知，无法与 E1A 的组内变异做对等比较。
3. 因此本章对组间差异的表述统一采取**"基于 n=3 方差基准的探索性判读"**，不使用"显著""证明""稳定优于"等推断性措辞。

### 4.9.4 可以陈述的

1. 在本仿真设定下，**谣言相关互动在第 1 轮达到峰值、并在第 5 个模拟小时前后自然衰减至接近零**；该形态经 E1A 三次重复一致复现，且在有无官方干预的条件下共同出现。
2. 各条件的辟谣相关互动始终是谣言相关互动的 **4.7–7.9 倍**，讨论结构从一开始就被官方/求证框架主导。
3. **有辟谣介入的三个条件，谣言相关互动与占比均低于无干预基线，且方向在两种口径下一致**（4.9.2）。这是本研究中最值得后续验证的一条线索，但仍受 4.9.3 三条限定约束。
4. **介入时点早晚之间未见单调关系**；**回应形态的观测方向与假设相反**。二者均不构成 "某时点/某形态更优" 的证据。

### 4.9.5 不能陈述的

1. **不能**声称某一介入时点或某一回应形态"更有效"——前者无单调关系，后者方向与假设相反且可能来自未控制的文本差异。
2. **不能**把"谣言相关活动衰减至零星"解释为治理成效——未受任何干预的基线组同样在第 5 轮后降至该水平。
3. **不能**把上述结果解读为"现实中辟谣无效"。4.10 给出的**地板效应**表明，本仿真的 Agent 构成会系统性压缩可观测效应，因此即便第 3 条成立，其效应量也被严重低估。
4. **不能**进行跨环境下的任何外推。

## 4.10 最主要的效度限制：Agent 构成导致的地板效应

本节是对 4.9.5 第 3 条的具体展开，也是本项目最重要的自我诊断。

**这一节必须与 4.9.2 的结论同时阅读**：4.9.2 显示"有无辟谣介入"出现了超出噪声的分离，
而本节说明该分离是在一个被结构性压缩的测量环境中观察到的——
因此**观测到的效应量应当被视为下限，而非对现实效应量的估计**。

8 个 Agent 的构成如下：

| 类型 | 数量 | 立场（配置值） |
|---|---|---|
| 公安机关（ GovernmentAgency） | 3 | supportive |
| 浦东警方（Organization） | 1 | supportive |
| 中国互联网联合辟谣平台（MediaOutlet） | 1 | supportive |
| **官方/机构小计** | **5 / 8** | — |
| 普通网民（Person） | 2 | neutral / opposing |
| 自媒体（RumorForwarder） | 1 | opposing |
| **非官方小计** | **3 / 8** | — |

后果是：**即使研究者完全不注入任何官方辟谣**（E1A 基线），环境中也有 5 个立场为 supportive 的机构 Agent 会自发持续产出辟谣内容。实测数据印证了这一点——基线组（E1A，3 次重复）在未注入任何干预的情况下，
仍自发产生 43.5 条辟谣类内容与 82.0 次指向辟谣的互动，辟谣相关互动是谣言相关互动的约 5.7 倍。

从话语内容看，3 个非官方 Agent 在第 1–2 轮短暂扩散谣言后，随即在后续轮次大量转为"我以前也爱转，现在不敢了""我就是那个高某某，我认这个错"式的**悔过与劝阻**话语。这使得谣言侧的活动上限被结构性压低，形成典型的**地板效应**：

- 谣言侧没有足够的活动空间，任何干预的边际效果都会被淹没；
- 由于所有条件的初始值都已接近下界，组间差异在物理上难以显现。

**因此，本实验结果应被理解为"在该 Agent 构成下，可观测的干预效应被压缩到接近检出边界"，而不是"干预没有效应"。** 4.9.2 中相对于基线低约 5 条的差异，出现在一个谣言侧总量本就只有约 20 条、且被 5 个官方账号持续对冲的环境里——它既可能是干预的真实作用，也可能是构成失衡下的残留信号。

要使实验具备充分检出能力，必须提高非官方 Agent 的比例与绝对数量，使谣言侧存在可观测的、可持续的自发传播过程。这一点已列为首要改进方向（见 4.11 与 `progress.md`）。

## 4.11 稳健性分析与不足

1. **重复次数不足（首要不足）**。仅 E1A 完成 3 次重复，其余五个条件各 1 次，目标为每条件 ≥3 次。未完成的原因是账户余额耗尽且 DeepSeek 采用延迟入账使实时读数不可信（见 4.8.1），而非技术故障。由此产生的直接后果写在 4.9.3：**组间差异只能以 E1A 的组内变异为尺度做探索性判读，不能做推断性检验**。
2. **Agent 构成失衡（地板效应）**。5/8 为官方或机构角色，见 4.10。这是当前最限制结论力的因素，其重要性高于重复次数问题。
3. **Agent 规模偏小**。8 个 Agent 使逐轮指标受单个 Agent 行为的影响过大。Agent 数量由 `Zep 图谱实体数 × 0.9` 推导、不可手工指定，扩充必须回到种子材料与图谱构建阶段。
4. **早期两组与后续运行使用了不同的执行路径**。E1A_rep1 与 E1B_rep1 经后端接口派生，
   其余经 `run_direct.py` 直连运行器（原因是接口派生的子进程曾出现静默退出）。
   两者产物结构一致（同一份 `actions.jsonl`），且共享同一套配置与审计标准，
   但严格说不属于同一执行路径，已在交付文档中标注。
5. **平台单一**。只运行 Reddit 讨论类平台，不做跨平台外推；Twitter 通道因依赖在线模型加载而不可用（4.2.2）。
6. **转发缺失**。`REPOST` 计数恒为 0，无法观察转发级联，无法重建传播树。
7. **内容立场仍是启发式规则**。虽经逐条人工核校并重构，仍可能在未见过的语式上出错；全部判定随成果归档以供复核。
8. **干预机制为二次开发补丁**。上游 `scheduled_events` 是死字段，本项目通过受控补丁实现定时注入；注入时机与内容可核验，但属于对上游代码的定制修改。
9. **Zep 情景记忆的跨运行累积未完全排除**。已确认数据库与动作日志在每组运行前被清除、初始态一致；但图谱记忆理论上可能累积。间接证据是六个条件的辟谣相关互动为 122/109/124/126/109/117（E1A 取三次均值），**不随运行次序单调上升**，暂无累积迹象。更直接的检验是 E1A 的三次重复横跨整个补跑期，其谣言相关互动为 20/22/22，**未见随时间推移的趋势**，这为"无显著累积"提供了较强的支持。
10. **LLM 采样不可复现**。固定 `random_seed` 后模型输出仍有随机性，因此重复实验不是可选的补充，而是必备条件。
11. **现实合理性验证的层次很低**。见 4.12，仅做了形态层面的弱对照。

## 4.12 有限的现实合理性验证

本次只做了**形态层面**的合理性检查，没有把仿真曲线与现实曲线逐点对齐：

- **真实侧**（`mirofish/seed/real_timeline.csv`，官方辟谣帖评论的小时级序列）：在首次官方通报（08:35，浦东警方）之后，评论量在随后 1 小时内达到峰值，随后逐步回落。
- **仿真侧**：谣言相关互动在初始注入后的第 1–2 轮达到峰值，随后衰减。

两者都呈现"爆发后衰减"的整体形态，构成一个**弱的、方向性**的一致性。

**必须声明**：真实序列的观测对象是"官方辟谣帖下的评论"，仿真序列的观测对象是"谣言相关互动"，两者观测对象、时间起点、指标定义均不同，**不能**解释为同一现象。它只能作为"模型行为没有出现与常识相悖的单调递增或长平台"这类最低限度的合理性佐证。**考虑到 4.10 揭示的地板效应，本仿真在传播强度上与现实不具备可比性。**

## 4.13 治理启示、适用条件与边界

在**本仿真设定下**（8 Agent、其中 5 个为官方/机构、Reddit、活跃度被抬升、多数条件单次运行），可以给出的**条件性观察**是：

1. 在官方声音占主导的信息环境中，涉灾谣言相关讨论会**自行快速收敛**，官方介入的边际可观测效果很小；
2. 因此，仿真所观察到的差异尚未达到可以被解释为"时点效应"或"形态效应"的强度；
3. 相反，更稳健的观察是**讨论结构的失衡**——辟谣相关互动始终为谣言相关互动的 5–7 倍，提示真正值得关注的治理问题可能不是"辟谣够不够快"，而是"究竟哪些人群处于官方声音覆盖不到的位置"。

这些观察**不构成**对现实政策的效果建议。其成立条件包括：该仿真环境、该 LLM、该活跃度参数、该 Agent 群体构成、该内容立场判定规则；任一改变都可能改变结果。

本章的定位是：**提供一组经过数据质量复核的、可复现的探索性反事实仿真结果，并诚实报告其阴性结果与地板效应成因**，为第五章的治理机制讨论提供一种微观行为视角；本章不宣称识别了任何因果效应，也不提供可直接外推的参数。
