# 仿真实验设定与参数说明（约 600 字）

## 平台与底座

本研究采用开源多智能体仿真引擎 MiroFish（上游 Commit `7657031`），底层为 CAMEL-AI 的 OASIS 模拟器，Agent 长期记忆由 Zep Cloud 知识图谱管理，个体决策由 `deepseek-chat` 模型按画像自主生成。受 HuggingFace 在线模型下载不稳定影响，且预实验实测评论、点赞等互动几乎全部发生于 Reddit 通道，正式实验统一以 **Reddit 讨论类平台**运行；时间尺度 `minutes_per_round = 60`，即 1 轮 = 60 模拟分钟，未做现实时间校准。

## 种子与 Agent

种子材料由真实数据构成：台风"白海豚"官方定性通报 5 条、客观灾情与治理事实 35 项、脱敏公众反应样本与造谣语料。经本体抽取与 Zep 图谱构建后得到 **8 个 Agent**（数量由图谱实体数自动推导，不可指定），涵盖本地自媒体、AI 造假者、多层级公安机关与国家级辟谣平台。为使传播可被观测，统一覆写了活跃度参数（全时段可活动、`activity_level=0.9`、每轮激活 6–8 个 Agent）——这是建模假设而非现实标定，所有条件保持一致以保证组间可比。

## 干预与对照

三组实验共用同一批 Agent、同一网络与同一份种子。实验一比较传统文字谣言（E1A，兼作共同基线）与 AIGC 高拟真图文谣言的**文本代理刺激**（E1B，MiroFish 不支持真实图片输入，此限制已如实声明）。实验二在相同的公文式辟谣（改写自真实通报 P1-01）下比较第 1、4、12 模拟小时介入，干预通过对上游补齐的 `scheduled_events` 补丁精确注入并在日志中核验。实验三比较公文式与数智实证式辟谣（含雨量、保供、AI 造假识别等可核验实数）。

## 实际执行情况

受 DeepSeek 余额限制，实际完成 E1A、E1B、E2R1、E2R4 各一次；E2R12 与 E3B 未运行。观测指标全部取自真实动作日志：逐轮互动量、谣言/辟谣立场分类、互动指向性、参与广度、峰值与达峰轮次。恐慌率、囤货率等无对应字段，不予量化。
