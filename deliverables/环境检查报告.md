## 6. 解阻塞操作（用户侧，一次即可）

在 `C:\Users\Kevin\Desktop\MiroFish\` 新建 `.env`（**不入库**，已 gitignore）：

```ini
LLM_API_KEY=<你的阿里云百炼/DeepSeek Key>
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL_NAME=qwen-plus
ZEP_API_KEY=<https://app.getzep.com/ 免费注册获取>
```

预算说明：Zep Cloud 免费额度按调用次数计，配 30 元 LLM 预算可支撑烟雾测试（8 轮）+ 实验一基线；三组实验全量（6 次 × ≤15 轮）建议先跑烟雾测试校准实际 token 消耗后再评估。

启动验证命令（填好 Key 后）：

```bash

npm run backend   # 期待输出 "MiroFish Backend 启动完成"，:5001
# 另开终端：
curl http://localhost:5001/health   # {"status":"ok","service":"MiroFish Backend"}
```
