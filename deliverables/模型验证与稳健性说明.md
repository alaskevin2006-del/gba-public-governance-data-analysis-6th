# 模型验证与稳健性说明

**版本**：2026-10-21（对应 `analyze_formal_v2.py` 去重重算后的数据）

---

## 1. 技术有效性检查（五项，均有实测证据）

| # | 检查项 | 方法 | 结果 |
|---|---|---|---|
| 1 | Agent 是否真实活跃 | 检查 `active_hours` 与调度分支 | 已定位并修复：LLM 生成的 `active_hours` 限定在工作时段，而仿真自 hour 0 起始，`if current_hour not in active_hours: continue` 跳过了全部自主动作。现统一覆写为 0–23 时、`activity_level=0.9` |
| 2 | 是否产生真实传播互动 | 逐轮统计动作类型 | 评论、点赞、点踩均已稳定出现；**`REPOST` 恒为 0**，故不把发帖量称为"传播规模" |
| 3 | 初始状态是否可控 | 核对 round 0 | 全部条件均为研究者设定的同样 4 条谣言帖；LLM 自造初始帖被移除（每次记录移除条数）。图谱自带的官方类 Agent 仍会自主发辟谣内容，属被允许的自主行为 |
| 4 | 干预是否真正生效 | 以干预文本唯一标记串检索 `actions.jsonl`，核验首次出现轮次 | 6 次运行全部 `on_time=true`，核验结果写入各自 `run_meta.json` |
| 5 | 指标能否正确解析 | 用日志中的 `round_start`/`round_end` 还原轮次 | 已解决早前"16 轮只解析出少数几轮"的问题 |

**新增第 6 项（本轮补上）**：**完成度审计**。仅凭退出码 0 会把"余额耗尽导致的中断"误判为成功。
现对每个运行统计 HTTP 402 次数与逐轮动作覆盖，缺轮或出现 402 即标记 `INVALID`。
本轮据此作废了 4 次运行——**这正是早先错误结论的来源**。

## 3. 稳健性结论：能支持什么、不能支持什么

### 3.1 唯一可用的方差参照

只有基线组 E1A 完成 2 次重复：谣言相关互动 20 与 22（极差 2）；
六个条件的组间极差为 9（16 至 25）。

- 组间极差约为已观测组内极差的 4.5 倍 → **方向上暗示差异可能不全是噪声**；
- 但 2 个样本的极差**严重低估真实方差** → **不能据此做显著性判断**。

**因此本轮全部以探索性描述给出，不含推断统计量，不使用"显著""稳定证明"等措辞。**

### 3.2 最限制结论力的因素：地板效应（而非重复次数）

8 个 Agent 中 5 个是官方/机构且立场 supportive，导致：

- 不注入干预的基线也会自发产生大量辟谣内容（43.5 条辟谣内容 + 82.0 次指向辟谣互动）；
- 谣言侧活动上限被结构性压低，任何干预的边际效果都会被淹没；
- 3 个非官方 Agent 在第 1–2 轮后迅速转为"悔过/劝阻"话语。

**这是比"只跑了 1 次重复"更根本的限制**：即使把重复次数补到 3 次，
在该 Agent 构成下也难以产生可检出的组间差异。因此下一步的首要动作是
**提高非官方 Agent 的比例与绝对数量**，而不是单纯加重复。

### 3.3 可以稳健陈述的三条

1. 在本仿真设定下，谣言相关互动在**第 1–2 个模拟小时达峰并在第 5 个模拟小时前后衰减至零星**，该形态在有无官方干预时共同出现。
2. 各条件辟谣相关互动始终是谣言相关互动的 **4.7–7.9 倍**，讨论结构从一开始就被官方/求证框架主导。
3. 三组实验**均未提供支持原假设的证据**（时点、形态、形式三方面皆然）。

### 3.4 不能陈述的

1. 不能声称某时点/某形态"更有效"；
2. 不能把"谣言活动衰减"解释为治理成效；
3. 不能把阴性结果解读为"现实中辟谣无效"——地板效应是更合理的解释；
4. 不能做任何跨环境外推，也不能把模拟小时当作现实小时。

## 4. 已知局限清单

1. 除 E1A 外每个条件仅 1 次重复（目标 ≥3 次，因账户余额耗尽未完成）；
2. Agent 构成失衡：5/8 为官方或机构（地板效应）；
3. Agent 规模 8 个，逐轮指标受单个 Agent 影响过大；Agent 数由图谱实体数推导，不可手工指定；
4. E1A_rep1 与 E1B_rep1 经后端接口派生，其余经 `run_direct.py` 直连，执行路径不完全一致（产物结构一致）；
5. 仅 Reddit 平台，Twitter 通道因依赖在线模型加载不可用；
6. `REPOST` 恒为 0，无法重建传播树；
7. 内容立场仍为启发式规则（已逐条核校，仍可能在新语式上出错）；
8. 定时注入属对上游代码的定制补丁；
9. Zep 情景记忆跨运行累积未完全排除；
10. LLM 采样不可复现固定 seed 后仍有随机性 → 重复实验是必备条件而非可选补充；
11. 现实合理性验证仅停留在形态层面的弱对照。
