# 模型验证与稳健性说明

**版本**：2026-10-21 深夜修订（对应 E1A 补齐至 3 次重复后的数据）
**数据**：`analyze_formal_v2.py` + `summarize_reps.py` 输出

---

## 1. 技术有效性检查（五项，均有实测证据）

| # | 检查项 | 方法 | 结果 |
|---|---|---|---|
| 1 | Agent 是否真实活跃 | 检查 `active_hours` 与调度分支 | 已定位并修复：LLM 生成的 `active_hours` 限定在工作时段，而仿真自 hour 0 起始，`if current_hour not in active_hours: continue` 跳过了全部自主动作。现统一覆写为 0–23 时、`activity_level=0.9` |
| 2 | 是否产生真实传播互动 | 逐轮统计动作类型 | 评论、点赞、点踩均已稳定出现；**`REPOST` 恒为 0**，故不把发帖量称为"传播规模" |
| 3 | 初始状态是否可控 | 核对 round 0 | 全部条件均为研究者设定的同样 4 条谣言帖；LLM 自造初始帖被移除（每次记录移除条数）。图谱自带的官方类 Agent 仍会自主发辟谣内容，属被允许的自主行为 |
| 4 | 干预是否真正生效 | 以干预文本唯一标记串检索 `actions.jsonl`，核验首次出现轮次 | 6 次运行全部 `on_time=true`，核验结果写入各自 `run_meta.json` |
| 5 | 指标能否正确解析 | 用日志中的 `round_start`/`round_end` 还原轮次 | 已解决早前"16 轮只解析出少数几轮"的问题 |

**新增第 6 项（本轮补上）**：**完成度审计**。仅凭退出码 0 会把"余额耗尽导致的中断"误判为成功。
现对每个运行统计 HTTP 402 次数与逐轮动作覆盖，缺轮或出现 402 即标记 `INVALID`。
本轮据此作废了 4 次运行——**这正是早先错误结论的来源**。

## 3. 稳健性结论：能支持什么、不能支持什么

### 3.1 方差基准：E1A 完成 3 次重复

判断组间差异能否归因于实验变量，唯一可靠的参照是**在完全相同条件下重复运行所产生的波动**。
基线组 E1A 现已完成 3 次重复（跨多批次、不同时段执行）：

| 指标 | 三次观测 | 均值 | 样本标准差 | 极差 |
|---|---|---|---|---|
| 自发互动总量 | 151 / 153 / 140 | 148.0 | 7.00 | 13 |
| **谣言相关互动** | 20 / 22 / 22 | **21.3** | **1.15** | 2 |
| 辟谣相关互动 | 127 / 124 / 115 | 122.0 | 6.24 | 12 |
| 谣言相关占比 | 13.25% / 14.38% / 15.71% | 14.4% | 1.23 pp | 2.46 pp |

以此作为噪声尺度，并同时用**绝对值口径**与**占比口径**（后者消除总活跃度差异）计算各条件
相对基线的 σ 倍数：

| 条件 | 谣言相关互动 | 绝对值 σ | 谣言相关占比 | 占比 σ | 两口径方向 |
|---|---|---|---|---|---|
| E1B AIGC | 23 | +1.4σ | 17.4% | +2.4σ | 一致（高） |
| E2R1 第 1 小时 | 16 | **−4.6σ** | 11.4% | **−2.5σ** | 一致（低） |
| E2R4 第 4 小时 | 16 | **−4.6σ** | 11.2% | **−2.6σ** | 一致（低） |
| E2R12 第 12 小时 | 17 | **−3.7σ** | 13.1% | −1.1σ | 一致（低） |
| E3B 数智实证式 | 25 | **+3.2σ** | 17.2% | +2.3σ | 一致（高） |

**这是本项目首次获得超出噪声的组间分离**：三个有辟谣介入的条件在两种口径下都低于基线。

**但 σ 倍数不是 p 值，必须附带三条限定：**

1. E1A 的标准差基于 **n = 3**。三个样本估出的标准差本身极不稳定，真实值有相当可能落在
   估计值的 0.5–2 倍之间；若真实组内标准差大一倍，上表所有 σ 倍数都要折半。
2. 其余五个条件**均只有 1 次观测**，单次抽样误差未知，无法与 E1A 的组内变异做对等比较。
3. 因此全项目对组间差异的表述统一为**"基于 n=3 方差基准的探索性判读"**，
   不使用"显著""证明""稳定优于"等推断性措辞。

**因此本轮结果属于探索性证据，不构成统计意义上的因果结论。**

> E1A 三次跨批次执行（20261022 / 20261023 / 20261024），谣言相关互动为 20 / 22 / 22，
> **未见随时间漂移的趋势**，同时为"Zep 情景记忆未随运行累积"提供了正向支持。

### 3.2 最限制结论力的因素：地板效应（而非重复次数）

#### 构成明细（`simulation_config.json` → `agent_configs`，六个条件完全相同）

| Agent | 实体类型 | 立场 | 在传播链中的角色 |
|---|---|---|---|
| 温州网民 | Person | neutral | 可被说服的普通公众 |
| 高某某 | Person | opposing | 谣言当事人（自带辟谣动机） |
| 自媒体 | RumorForwarder | opposing | 唯一的放大者角色 |
| 上海公安机关 | GovernmentAgency | supportive | 官方发布者 |
| 浙江宁波公安机关 | GovernmentAgency | supportive | 官方发布者 |
| 温州公安机关 | GovernmentAgency | supportive | 官方发布者 |
| 浦东警方 | Organization | supportive | 官方发布者 |
| 中国互联网联合辟谣平台 | MediaOutlet | supportive | 官方发布者 |

**8 个 Agent 中 5 个为官方/机构且立场全为 supportive，占比 62.5%。**
真正处在"可能被谣言说服并转发"位置的只有 2 个（温州网民、自媒体），
高某某虽为 Person 但角色设定是辟谣当事人。可用于承载"传播增量"的空间极小。

由此导致：

- 不注入干预的基线也会自发产生大量辟谣内容（46.0 条辟谣内容 + 76.0 次指向辟谣互动）；
- 谣言侧活动的上限被结构性压低，任何干预的边际效果都会被淹没；
- 3 个非官方 Agent 在第 1–2 轮后迅速转为"悔过/劝阻"话语。

**因此，即便 3.1 中观测到三个介入组低于基线，也应理解为"可观测效应被压缩到接近检出边界"，
而不是对现实效应量的估计。**

#### 关于"是否扩充普通公众 Agent"的评估（结论：应当扩充，但本期未做）

| 维度 | 评估 |
|---|---|
| 必要性 | **高**。构成失衡已构成结构性地板效应，会把真实效应压缩到检出边界附近，也使阳性线索无法归因 |
| 技术可行性 | Agent 数由 `Zep 图谱实体数 × 0.9` 推导，**不可手工指定**；必须回到种子材料扩充后重建图谱与画像 |
| 成本 | 重建图谱需 LLM 抽取实体/关系，且六条件必须在**新规模下全部重跑**（旧数据不可混用），估算 ¥15–20 |
| 本期为何未做 | 本期余额用于把各条件的重复次数补齐（这是支撑任何组间比较的前提）；两项无法同时完成 |
| 触发条件 | 若后续要把本仿真作为论文的主证据，**或要把 3.1 中的介入效应线索写成结论**，则必须先扩充公众 Agent 再在新规模下重跑，否则该线索无法排除构成偏差 |

> 该评估已作为后续工作的优先项记录，未以任何形式折减本期结论的表述强度。

### 3.3 可以稳健陈述的四条

1. 在本仿真设定下，谣言相关互动在**第 1 轮达峰并在第 5 个模拟小时前后衰减至零星**，
   该形态在有无官方干预时共同出现，**且经 E1A 三次重复一致复现**。
2. 各条件辟谣相关互动始终是谣言相关互动的 **4.7–7.9 倍**，讨论结构从一开始就被官方/求证框架主导。
3. **有辟谣介入的三个条件，谣言相关互动与占比均低于无干预基线，两种口径方向一致**
   （绝对值口径 −3.7 至 −4.6σ，占比口径 −1.1 至 −2.6σ）。这是本研究最值得后续验证的线索，
   但仍受 3.1 三条限定的严格约束。
4. **介入时点早晚之间未见单调关系**（16 / 16 / 17）；**回应形态的观测方向与假设相反**
   （E3B 25 > E2R4 16）。二者均不构成"某时点/某形态更优"的证据。

### 3.4 不能陈述的

1. 不能声称某一介入时点"更有效"（无单调关系）或某一回应形态"更有效"
   （方向与假设相反，且可能来自未控制的文本差异）；
2. 不能把"谣言活动衰减"解释为治理成效——未受任何干预的基线组同样在第 5 轮后降至该水平；
3. 不能把本期结果解读为"现实中辟谣无效"。3.2 的地板效应表明 Agent 构成会
   系统性压缩可观测效应，**观测到的效应量应视为下限而非对现实效应量的估计**；
4. 不能做任何跨环境外推，也不能把模拟小时当作现实小时。

## 4. 已知局限清单

1. **重复次数不足（首要局限）**：仅 E1A 达 3 次，其余五个条件各 1 次（目标 ≥3 次）。
   因 DeepSeek 延迟入账使余额读数不可信，本轮补跑 ¥9.86 仅完成 1 次有效运行（单次真实成本约 ¥4–5）。
   后果是所有组间判读只能用 E1A 的组内变异做噪声尺度，不能做推断性检验；
2. Agent 构成失衡：5/8 为官方或机构（地板效应，见 3.2）；
3. Agent 规模 8 个，逐轮指标受单个 Agent 影响过大；Agent 数由图谱实体数推导，不可手工指定；
4. E1A_rep1 与 E1B_rep1 经后端接口派生，其余经 `run_direct.py` 直连，执行路径不完全一致（产物结构一致）；
5. 仅 Reddit 平台，Twitter 通道因依赖在线模型加载不可用；
6. `REPOST` 恒为 0，无法重建传播树；谣言侧互动主要是对初始帖的即时点赞/点踩，缺少持续二次传播；
7. 内容立场仍为启发式规则（已逐条核校，仍可能在新语式上出错）；
8. 定时注入属对上游代码的定制补丁；
9. Zep 情景记忆跨运行累积未完全排除，但 E1A 三次跨批次结果（20/22/22）无漂移趋势，提供了反向证据；
10. LLM 采样不可复现固定 seed 后仍有随机性 → 重复实验是必备条件而非可选补充；
11. 现实合理性验证仅停留在形态层面的弱对照；
12. **成本不可预测性**：DeepSeek 延迟入账使实时余额读数不可作为预算依据，
    这是本轮重复实验未能按计划完成的直接技术原因。
