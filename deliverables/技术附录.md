## 2. 参数字典

| 参数 | 取值 | 依据 | 性质 |
|---|---|---|---|
| Agent 画像配额 | 长辈20/学生25/造谣5/营销8/KOL10/政务7/亲历25（%） | Seed §7 + 立场偏斜修正 | 半实证 |
| 初始立场比（恐慌:求证:谴责） | 3:4:3 | 辟谣帖采样偏斜（谴责88.9%）校正 | 假设 |
| 轮次上限 | 15 | Token 成本控制 | 工程决策 |
| 烟雾测试规模 | 8 轮 | 校准 token 消耗 | 工程决策 |
| 时间压缩映射 | 1 轮 ≈ 2 小时 | 实验二 1/4/12h → 第 1/2/6 轮注入 | 模型配置（未现实校准） |
| 实验二介入轮 | 第 1 / 2 / 6 轮 | 上条映射 | 实验设计 |
| 实验三注入轮 | 第 2 轮（≈4h） | 与实验二中组对齐 | 实验设计 |
| 图 4-3 拓扑 | Watts–Strogatz n=100, k=6, p=0.08, seed=42 | 小世界示意 | 示意模型（非仿真导出） |
| panic_threshold | 3–5 条同向信息 | 待调参校准 | 假设 |
| verify_cost / trust_decay / reach_multiplier | 待校准 | — | 假设 |

## 4. 复现命令（总览）

```bash
# 环境（一次性）
cd C:/Users/Kevin/Desktop/MiroFish && npm run setup:all   # 含 uv sync（自动建 Python 3.12 venv）
# 填入 MiroFish/.env（LLM_API_KEY + ZEP_API_KEY）后：
npm run backend   # :5001

# 图表（离线可复现）
python scripts/figures/fig_1_1_tech_route.py
python scripts/figures/tab_2_2_facts_vs_rumors.py
python scripts/figures/fig_4_3_network_topology.py
python scripts/figures/fig_5_1_governance.py
python mirofish/scripts/build_real_timeline.py

# 仿真（需 Key）
python mirofish/scripts/run_simulation.py --exp 1 --smoke      # 烟雾测试
python mirofish/scripts/run_simulation.py --exp 1              # 实验一
python mirofish/scripts/run_simulation.py --exp 2 --inject-hour 1   # 依次 1/4/12
python mirofish/scripts/run_simulation.py --exp 3A
python mirofish/scripts/run_simulation.py --exp 3B
python mirofish/scripts/parse_results.py <raw_export.json>
python mirofish/scripts/compute_metrics.py mirofish/results/*/per_round.csv
python mirofish/scripts/plot_fig_4_1_4_2.py all
```
