# 实验一 · 基准扩散破坏力（无政务干预）

> **目的**：测出"什么都不做"的基线——谣言在真空里能烧多大。
> 这是实验二、实验三的比较基准，必须先跑。

## 1. 变量设置

| 项 | 设定 |
|---|---|
| 种子材料 | `seed/seed_main_baihaitun.md`（全量） |
| 政务通报注入 | **无** |
| 情景注入文本 | 无 |
| Agent 总数 | 80（正式）／20（试跑校准） |
| 画像配额 | 按主种子 §7：长辈 20% · 青年 25% · 造谣者 5% · 营销号 8% · 辟谣KOL 10% · 政务号 7% · 亲历者 25% |
| 轮次 | 15（先跑 8 轮看形状） |
| 平台 | 双平台并行（MiroFish 默认） |

> 注：政务号 Agent 保留但不主动发布，仅作为"沉默的权威"存在，
> 用于测量"官方在场但不发声"时的舆论真空效应。

## 2. 预测需求（复制到界面）

```
在不注入任何官方通报的前提下，推演台风"白海豚"涉灾 AI 谣言在社交平台的扩散过程。
需要回答：
1. 公众恐慌情绪的峰值出现在第几轮，峰值强度如何度量；
2. 参与线下物资抢购的 Agent 比例随时间的变化；
3. 谣言从首发到跨圈层扩散（触达非本地用户）用了多少轮；
4. 谣言生命周期的自然衰减拐点在哪里。
请输出：情绪强度时序数据点、抢购比例数值、扩散路径中的关键节点账号类型。
```

## 4. 结果解读提示

- 若**抢购参与率 > 30%**：说明本事件具备"恐慌—囤货"强耦合，实验二的窗口效应值得测。
- 若**跨圈层扩散 < 3 轮**：说明地理位置锚（浦东/金山）不足以约束传播，需在报告中强调"地域标签失效"。
- 若**自然衰减拐点出现于 10 轮后**：说明谣言不会自愈，必须外部干预——这是政策建议的实证支点。
- 若恐慌峰值出现在**前 4 轮**：与实验二"1 小时黄金期"假设互相印证。
