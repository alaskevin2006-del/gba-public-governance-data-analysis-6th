# 实验三 · 治理回应形态对冲（A 公文辟谣 vs B 数智实证）

> **目的**：固定介入时点，只换通报形态，测"怎么说"比"什么时候说"差多少。
> **核心产出**：同一时点下两条情绪曲线的分叉程度——用来论证"用数据替代说教"。

## 1. 变量设置

| 项 | G-A（对照组） | G-B（实验组） |
|---|---|---|
| 种子材料 | `seed/seed_main_baihaitun.md` | 同左（完全一致） |
| 注入轮次 | **第 2 轮结束**（≈ 起势后 4 小时） | 同左 |
| 注入文本 | `seed/inject_scenario_A_公文辟谣.md` | `seed/inject_scenario_B_数智实证.md` |
| 唯一变量 | 通报形态 | 通报形态 |
| Agent 总数 | 80 | 80 |
| 画像配额 | 主种子 §7 | 同左 |
| 轮次 | 15 | 15 |

**为什么选第 2 轮**：实验二会给出衰减曲线的斜率，第 2 轮（≈4h）通常处在
"恐慌仍在爬升但尚未固化"的区间，是形态差异最容易显现的位置。
若实验二显示峰值出现在第 1 轮，则本实验改到第 1 轮注入。

## 2. 两版文本的结构差异（这是自变量本身）

| 维度 | A 版 | B 版 |
|---|---|---|
| 字数 | 约 80 字 | 约 600 字 |
| 可核验数字 | 0 | 18 |
| 具体地名 | 无 | 浦东、金山、宝山、徐家汇 |
| 逐条对应谣言 | 无 | 有（5 段对应 5 类谣言） |

| 语气 | 警示、收束 | 陈述、给据 |

## 3. 预测需求（复制到界面，两组同一份）

```
在第 2 轮注入官方通报后，重点观察回应形态对以下四类行为的影响：
1. 抢购行为的抑制程度（比例及其退潮速度）；
2. 求证型 Agent 的追问对象变化——是继续问"是不是真的"，还是转向问"数据来源"；
3. 营销号的选题迁移——是否因通报信息量大而改炒衍生议题（如企业罚款、物价）；
4. 官方账号的信任评分变化轨迹（关注是否出现"辟谣反噬"）。
请分别输出 A 组与 B 组的逐轮数值，便于对照。
```

## 5. 判读标准

- **主结论**：B 组抢购退潮轮次显著少于 A 组 → 支持"数智实证型通报优于免责式公文"。
- **反向可能**：若 B 组因文本过长导致核心数据未被吸收（阅读完成率低），
  结论应转为"实证型通报需配短卡片/图解，纯长文无效"——这本身也是有价值的发现，不要藏着。
- **信任轨迹**：A 组若出现"先降后不升"，说明空泛通报会持续损耗公信力，是政策批判的关键证据。
- **营销号迁移**：若 B 组营销号转向"企业台风天罚款"等衍生议题，
  说明治理回应存在"议题挤出"效应——谣言被压下去了，但舆情总量没降。
