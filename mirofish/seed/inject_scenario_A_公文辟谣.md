# 情景 A 注入材料 · 传统免责式公文辟谣

> **实验用途**：实验三「治理回应形态对冲」对照组 · 实验二「黄金响应窗口」统一话术
> **设计定位**：仅注入官方文字通报，**不含**任何数据、图证、处置细节与情绪安抚。
> **注意**：本文件为实验构念文本，**不是**真实通报原文；真实通报见 `seed_main_baihaitun.md` §2。

---

## A-1 注入指令（在 MiroFish 场景配置中作为 `official_response` 变量）

```
【官方通报】

近日，网传我市发生人员伤亡及安置点停水停电等情况。经核实，相关信息系不实信息，
请广大网民不信谣、不传谣、不造谣。网络不是法外之地，对于编造、传播虚假信息的行为，
公安机关将依法予以查处。
```

## A-2 话术特征（便于实验后归因）

| 维度 | 本情景设定 |
|---|---|
| 信息颗粒度 | 泛化，无具体地名、无具体事件、无核实过程 |
| 数据密度 | 0 个可核验数字 |
| 责任归属 | 只指向"造谣者"，不回应公众关切 |
| 情感温度 | 中性偏冷，含警示语 |
| 可验证性 | 低——公众无法自行核对任何一条事实 |
| 预期效果 | 抑制恐慌能力弱，且可能因"什么都没说"反而强化不信任 |

## A-3 选此形态的现实依据

平台一 5 条真实通报中，P1-01 与 P1-03 的结尾均为同构的"警方提示"：

> 请市民群众不随意转发未经证实的信息，共同维护清朗的网络环境和良好社会秩序。

该类表述是当前基层政务辟谣的主流形态——**定性明确但事实供给不足**。
本情景即以此为原型抽象，用于测量"只给结论、不给证据"的传播效果上限。

## A-4 仿真观测点

- 注入后 1 轮内，转发量是否出现二次抬升（"辟谣反而扩散"效应）
- 求证型 Agent 的提问量变化（预期上升：通报未提供可核验锚点）
- 恐慌型 Agent 的囤货行为是否被抑制（预期：抑制有限）
- 对官方账号的信任评分变化（预期：小幅下降）
