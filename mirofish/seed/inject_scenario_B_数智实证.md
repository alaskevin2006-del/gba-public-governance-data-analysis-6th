## B-2 四段式结构与设计意图

| 段落 | 内容 | 对应打击的谣言 | 作用机制 |
|---|---|---|---|
| 一、逐条定性 | 点名具体谣言 + 核实结论 + 处罚结果 | R1 AI 坠楼 | 建立"官方确实在查"的可信度 |
| 二、安置实证 | 点位数、人数、物资件数、热水与客饭 | "安置点停水停电吃不上饭" | 用可感的服务细节替代抽象辟谣 |
| 三、排涝实证 | 闸次、立方米、泵车、泵站数 | "全城被淹" | 用工程量级压制画面冲击 |
| 四、保供实证 | 备货增幅、库存状态、价格 | "物资短缺、赶紧囤" | 直接切断囤货动机 |
| 五、手法拆解 | 四类套路 + 识别方法 | 全部 | 提升公众自身的辨别能力（赋能而非代替判断） |

## B-3 与情景 A 的差异对照

| 维度 | 情景 A | 情景 B |
|---|---|---|
| 可核验数字 | 0 | 18 |
| 具体地名 | 无 | 浦东、金山、宝山、徐家汇 |
| 核实过程 | 无 | 有（AI 生成、行政拘留） |
| 公众关切回应 | 无 | 逐项对应（安置、排水、物资） |
| 赋能属性 | 无 | 有（四类手法 + 识别方法） |
| 文本长度 | 约 80 字 | 约 600 字 |

## B-4 仿真观测点

- 囤货行为占比相对情景 A 的下降幅度（核心指标）
- 求证型 Agent 的追问是否转向"数据来源"而非"事件真伪"
- 营销号是否因"通报本身信息量大"而改变选题（预期：转向衍生议题）
- 官方账号信任评分相对情景 A 的抬升幅度
- 副作用观察：长文本是否降低阅读完成率，导致核心数据未被吸收
