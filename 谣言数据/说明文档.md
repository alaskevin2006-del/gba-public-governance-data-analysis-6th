## 二、数据字典（8 字段标准数据集）

| 字段 | 说明 |
|---|---|
| `id` | 博文 mid 或评论 id（微博唯一标识，可回溯） |
| `事件标签` | 白海豚 / 杜苏芮 / 摩羯台风谣言和ai造假事件 |
| `切片类型` | 切片A_求证恐慌型 / 切片B_争议反思谴责型 / 切片C_媒体热帖评论 |
| `发布账号` | 发帖或评论账号昵称 |
| `发布时间` | `YYYY-MM-DD HH:MM` |
| `点赞量` | 博文点赞数（`attitudes_count`）；评论为评论点赞数 |
| `原文文本` | 抓取原文，未做任何改写 |
| `清洗后文本` | 去 @ 用户、话题符号、URL、表情后的文本，繁体已转简体 |

`全量明细_含链接.csv` 额外提供 `来源类型`（博文／评论）、`博文链接`、`命中检索词`，用于逐条复核。

## 三、检索式设计

| 切片 | 检索词（每事件词前加事件名，如「白海豚 xx」「杜苏芮 xx」「摩羯 台风 xx」） |
|---|---|
| A 求证恐慌型 | 真的假的、求证实、听说、安置点、断水断电 |
| B 争议反思谴责型 | AI 造假、造谣 拘留、摆拍、营销号、严惩 |
| C 媒体热帖 | 辟谣 官方、通报（只取媒体／政务蓝 V 热帖及其评论） |
| 语义补位（补充轮） | 积水 被困、楼 塌、航班 取消、高速 封路、物资 短缺、超市 抢购、停电 没水 |

- 时间窗：白海豚 2026-08-08～08-30；杜苏芮 2023-07-28～08-15；摩羯 2024-09-05～09-25。
- 每个检索式取前 2–3 页（约 10–30 条），组间随机间隔 2–4 秒，避免触发限流。
- 切片类型最终由**文本规则**判定（非按检索词硬分）：评论一律归 C；媒体／政务账号发布且含辟谣、通报、回应、不实等表述者归 C；含 AI 生成、造假、摆拍、拘留、严惩、营销号等强谴责信号者归 B；含真的假的、求证实、听说等求证信号者归 A；其余按检索词所属切片回填。

## 四、清洗规则

1. 去 `@用户名`、`#话题#`（保留话题内文字，避免语义丢失）、URL、`网页链接` 占位符、`展开/收起`。
2. 繁转简（OpenCC `t2s`）。
3. 剔除：空白、汉字少于 2 个、信息量过低（≤3 汉字且无灾情语义）、纯表情、广告导流（加微信／代购／优惠券等，且不含辟谣／警方等官方语境）。
4. 去重：同用户同文本 → 再去跨账号完全相同文本（防止蓝 V 齐转发造成同一文本重复计数）。
5. 相关性约束：正文须命中事件名；「摩羯」须排除星座语义，「白海豚」须排除中华白海豚／钦州等生物保护语义；评论须挂在通过校验的博文之下（母帖无效即剔除）。
6. 全程不改写网民口语、不补标点、不做摘要。

## 六、LDA 建模设置（对应图 3-2）

- 工具：`scikit-learn` LatentDirichletAllocation；分词 `jieba` + 领域停用词表（含政务通稿套话、地名、语气词）。
- 向量化：CountVectorizer，`min_df=2`、`max_df=0.5`、`max_features=600`。
- 主题数：k=9（超参 α=0.15、β=0.02、batch 学习，6 组随机种子择优）。
- 归并：按议题关键词权重将 9 个子主题归并为三大议题，子主题明细见 `LDA_子主题明细.csv`。
- 结果：物资保供焦虑 34.3%、人身交通险情 37.3%、官方求证与谴责造谣 28.4%。
- 各议题 Top 词（图 3-2 摘要）：价格／市场／物资／超市／小区／断电／停电／断水；暴雨／洪水／灾害／积水／航班／取消；谣言／辟谣／造谣／网民／警方／流量／AI／编造。

## 七、局限与使用提示

1. **样本为检索式命中样本，非全量普查**。微博高级搜索对单检索式仅开放有限页，故各事件样本量在 320–380 条区间，适合探索性主题建模，不宜用于计算总体比例。
2. **旧事件评论缺失较多**。杜苏芮（2023）、摩羯（2024）部分政务帖评论已关闭或清空，切片 C 的评论量显著少于白海豚（2026），跨事件比较 C 切片时需谨慎。
3. **点赞量为抓取时点值**，随时间变化；旧帖的点赞数据为当前累计值，不等于事发期水平。
4. **合规**：数据仅用于学术研究，账号昵称保留原始形态但已在论文引用时建议做匿名化处理（如「用户A」）；不包含手机号、身份证等个人信息；请勿二次传播原文中的具体个人指控。
5. 若需扩展样本：改 `scripts/collect_search.py` 中 `SLICE_TERMS` 与日期窗后重跑，`clean_build.py`→`lda_topics.py`→`make_table.py` 可一键复现全部交付物。
